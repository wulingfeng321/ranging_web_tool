# AI 测量分析

## 启用 DeepSeek

推荐点击网站右上角 **管理 → AI 配置**。输入管理密码后，可以设置 API 地址、Key、模型 ID、思考模式、温度、输出 Token 上限和超时。保存后下一次分析生效；密钥不会回显，留空保留原值。配置保存不会发送测试请求或产生模型费用。

云端配置保存在 `/var/lib/ranging-studio-settings/ai.local.toml`，本地仍使用 `config/ai.local.toml`。网站公开时，启用 AI 后访客可以生成报告，消耗所配置密钥的额度。

本地文件 `config/ai.local.toml` 已准备好，首次从仓库获取时可复制 `config/ai.example.toml` 创建它。填写以下项目，其余参数可以保留默认值：

```toml
enabled = true
base_url = "https://api.deepseek.com"
model = "deepseek-flash"
api_key = "在本地填写你的 API Key"
```

`deepseek-flash` 是 2026-10-24 核对官方文档后使用的模型 ID，对应当时的 DeepSeek-V4.1-Flash-1017。模型后续可能升级，以[官方接入说明](https://api-docs.deepseek.com/zh-cn/)和[Chat Completions API 文档](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)为准。

真实密钥仅写入 `ai.local.toml`，不要写入受版本管理的示例文件或提示词。该文件已加入 Git 忽略。也可以设置 `DEEPSEEK_API_KEY` 环境变量，其优先级高于配置中的 `api_key`；设置新的环境变量后需重启服务。`RANGING_AI_CONFIG` 可指定其他配置文件路径。

双击 `start-local.cmd`，打开实验 → **AI 分析**，点击“刷新配置”。配置文件保存后自动用于下一次请求，不必重新构建网页。“已配置”只表示配置齐全，首次生成才会验证账户与模型的可用性。

## 使用与输出

1. 选择“测量汇总”“异常诊断”或“实验报告”。
2. 可补充分析重点，例如“判断误差主要是稳定偏置还是随机波动”。
3. 展开“查看待发送的数据与提示词”，检查或下载当前材料。
4. 点击“生成分析报告”。此时才发送到配置的 API 并产生调用费用。
5. 结果保存在本地 SQLite，刷新或切换实验不会丢失。可切换历史记录、导出 Markdown、下载包含当时提示词与数据的输入快照。

管理页提交的新密钥只发送到本站后端保存，读取配置时不会返回已有密钥；密钥不进入提示词、历史报告或输入快照。模型输出以 Markdown 安全渲染，忽略 HTML、图片及外部链接，不执行代码。

## 数据范围与分析口径

- 发送实验名称、备注、用户填写的真实距离、全量配对统计、解析警告、板卡采集配置、字段释义。
- 发送最多 100 条配对（含候选及关联事件）、每板 40 条状态、40 条 DSP、80 条事件时钟记录。超过上限按原始顺序等间隔抽样，含首尾；每组注明 total / included / method。
- 状态和 DSP 各数值字段额外提供全量 first / last / min / max，避免把累计计数器求和。极值保留原始字段值。
- 误差统计由程序对所有有换算距离的唯一配对计算，而非让模型从抽样值重新计算。没有真实距离时不计算准确度，也不从实验名字猜测。
- 不发送原始文件、PCM、音频或波形图。AI 无法据此直接进行听音、频谱或反射峰分析。
- 提示词明确区分唯一配对与最终测距通过、换算距离与固件显示距离、通信序号与本地事件编号、各板本地时间与主时钟，以及 ns / μs / ms / mm 单位。
- 总输入材料超过 240 KB 时拒绝请求并明确提示，不静默截断。输入预览的字符数不是精确 token 数；完成后显示服务方返回的 token 用量。

## 修改提示词和参数

提示词均为可编辑 UTF-8 文本，下一次生成生效：

- `config/prompts/system.md`：实验背景、数据字典说明、统计口径、分析限制。
- `config/prompts/summary.md`：测量汇总。
- `config/prompts/diagnosis.md`：异常诊断。
- `config/prompts/report.md`：实验报告。

默认关闭思考模式（`thinking = "disabled"`），使用 `temperature = 0.2`、`max_tokens = 6000`。需要更多推理时可改为 `thinking = "enabled"`，并提高输出上限；服务方思考 token 也可能占用输出预算。当前应用允许上限为 32,000 tokens。默认请求超时配置为 120 秒，允许 10–300 秒。

当前支持 DeepSeek 官方的 Chat Completions 格式。其他服务需兼容 `thinking` 参数；并非保证支持所有第三方中转接口。

## 历史和异常

同一服务实例只允许一个 AI 分析任务运行，避免重复点击产生多次调用。超时、限流或其他失败不自动重试，需用户手动重新生成；超时不保证服务方没有计费。服务重启时将未完成任务标记为失败。

每次记录保存模型、服务地址、生成参数、提示词、输入数据和指纹。修改实验名称、备注、真实距离或解析结果后，历史报告会提示基于旧数据；修改提示词只影响新报告，旧快照保持原样。界面显示最近 30 次历史，数据库保留全部记录。建议备份整个 `data/`。

功能仍用于本地单用户应用；公网认证和 Linux 部署属于后续阶段。本次未配置真实密钥，真实 DeepSeek 结果仍需配置后验证。
